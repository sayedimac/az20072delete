# Visual UI test artifacts

The workspace prompt at `.github/prompts/run the UI tests.prompt.md` uses this directory for visual Playwright evidence.

- `baselines/` contains approved reference images that may be committed.
- `artifacts/screenshots/` contains screenshots generated by local runs.
- `artifacts/traces/` contains Playwright traces or equivalent browser diagnostics.
- `artifacts/reports/` contains Markdown run reports.

Generated artifacts are ignored by Git. Keep stable baseline filenames descriptive, including the page or journey and viewport, and update baselines only after intentional visual changes are reviewed.
